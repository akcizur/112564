# BYLDR Engine 1.0.1

Static 3D building game for GitHub Pages.

Features:
- Three.js 3D builder
- Build / Erase
- Rotation
- Chunk organization
- LocalStorage save
- JSON import/export
- Undo / Redo
- Demo world
- Desktop + mobile controls
- No build step
- No backend

Deploy: GitHub → Settings → Pages → Deploy from branch → `main` / `/root`.

Controls:
- Mouse drag: camera
- Click: build / erase
- R: rotate
- Ctrl+Z / Ctrl+Y: undo / redo
- Mobile joystick: movement
- Jump: jump button
